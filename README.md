# 👥 Users Filter

Aplicação Angular para busca e filtragem de usuários em tempo real.

## 🔗 Demo

[usersfilter.vercel.app](https://usersfilter.vercel.app/)

## Sobre

Interface de listagem de usuários com filtros dinâmicos por nome, data de cadastro e status (ativo/inativo). Desenvolvida com foco em performance e responsividade.

## Funcionalidades

- Filtragem em tempo real por nome
- Filtro por status (ativo / inativo)
- Filtro por data de cadastro
- Design responsivo (mobile-friendly)

## Stack

- **Frontend:** Angular · TypeScript · SCSS · Angular Material
- **Deploy:** Vercel

# Instalar dependências
